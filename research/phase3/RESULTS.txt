ZipFit 3차 검증 및 로컬 MVP 결과 / 2026-10-01

수행한 작업
사용자 동의를 받아 기획·규칙 검증에서 로컬 무료 MVP 구현까지 진행했다.
공고문 8종의 쪽별 텍스트 자료를 보관하고 대표 조건·예외를 비교했다.
송파 청년안심주택 임대조건 표와 특별공급 자격 표, LH 모집권역을 PDF 렌더링으로 대조했다.
Python FastAPI + 브라우저 기본 HTML/CSS/JavaScript로 설치·실행 구성을 만들었다.
가입·결제·외부 LLM 호출 없이 같은 PC에서 사용한다.

데이터
초기 재현 카탈로그: 원본 게시물 370건, 제목 기반 모집 후보 301건.
2026-10-01 16:55 한국시간 최근 목록 재수집 후: 원본 게시물 394건, 모집 후보 324건.
기관별 저장 게시물 LH 205 / SH 60 / GH 49 / 서울 청년안심주택 50 / 청약홈 30.
위 숫자는 신청 가능한 집이나 현재 접수 중인 공고의 숫자가 아니다.
현재 총계와 출처별 갱신 시각은 화면 ‘수집 현황’ 및 /api/notices에서 확인 가능하다.
수집 기본 범위: 각 경로 최근 최대 2페이지, LH 약 60일, 청약홈 최근 월 구간,
SH·서울 최근 페이지, GH 임대·매입·본사 게시판. 과거 보관 자료는 삭제하지 않는다.
최종 실제 요청 16회: LH 2 / SH 2 / GH 6 / 서울 2 / 청약홈 4. 5개 기관 모두 오류 없이 완료.
첫 실행에서 LH 페이지 검색 상태값 때문에 같은 목록이 반복됐고 중복 페이지 검증이 이를 감지했다.
실제 게시판의 페이지 이동 폼 필드(srchY=N 등)를 반영해 수정하고 후속 실제 요청으로 확인했다.
GH 매입 게시판 2쪽은 9건/1쪽인 목록의 정상 빈 결과였다. 명시된 빈 상태 구조를 확인했다.

자동 판정
2개 공고, 5개 공급유형. 송파 청년/신혼 특별·일반 4개, LH 든든전세 기본조건 1개.
예시: 신혼 2인, 월소득 775만원, 자산 1.5억원, 차량 없음 등 기본조건 입력 시
송파 신혼 특별공급은 소득 한도 7,039,524원 초과, 일반공급 기본조건은 일치한다.
이 비교는 원본 PDF의 검토 범위와 유효 검토 시각에 한정되며 최종 자격 확정이 아니다.
미검토 공고는 목록 검색은 가능하고 ‘추가 확인 필요’로 남긴다.
개인 프로필은 서버 파일·DB·쿠키·localStorage에 저장하지 않는다.

검증
pytest 자동 검증 32개 통과.
공고일 나이 경계, 소득 1원 초과, 0원과 미입력 구분, 부모 소득 합산, 6인 가구 미확인,
혼인 2,555일 경계, 예비신혼 조건부 처리, 자동차 한도·특례, 거주지 조건과 우선순위 구분,
미성년 예외, 기준일 미확인 보류, 오래되거나 변경된 규칙 보류, 실제 보증금/월세 조합,
한국시간 마감 시각, 실제 목록 파일 해석, HTTP 200 오류 거부, 갱신 보존, API/PDF를 검증했다.
Chrome에서 데스크톱 1440×1050, 모바일 390×844 화면을 실행하고 스크린샷을 시각 확인했다.
예시 입력 → 판정 → 공고 상세 → 유형별 결과 → PDF 근거 링크, 기관·텍스트 필터,
빈 결과, 수집 현황, 새로고침 후 개인정보 초기화, 가로 넘침 없음, 콘솔 오류 없음 확인.
